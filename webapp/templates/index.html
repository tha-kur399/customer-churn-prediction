Project Machine Learning Architecture

This MCA Data Science project follows an enterprise modular ML lifecycle:

1
Data Ingestion & Stratified Splitting

Loads 7,043 customer records with 21 attributes, handles data validation, and partitions into 80% train and 20% test datasets.

2
Transformation & Feature Engineering

Standardizes numerical features with StandardScaler and encodes 16 categorical dimensions using OneHotEncoder wrapped in ColumnTransformer.

3
Multi-Algorithm Model Benchmarking

Trains & evaluates Logistic Regression, Decision Trees, Random Forest, AdaBoost, and Gradient Boosting with balanced class weights.

4
Inference & Retention Engine

Generates real-time churn probability, risk severity classification, key risk drivers, and prescriptive retention actions.
